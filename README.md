# Kibare : L'information comme identité

**L'information publique, en toute confiance..**


Prototype open source développé dans le cadre du Sprint Technique Pré-Hackathon 2026 (Hackathon 226 - Édition 2026).

## Stack

- Matrix (Synapse) — homeserver
- Element Web — client
- PostgreSQL — base de données
- Caddy — reverse proxy et TLS
